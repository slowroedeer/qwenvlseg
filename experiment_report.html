QwenVLSeg 实验报告
基于 Qwen3-VL-Seg (May 2026) 的轻量化复现

1. 研究背景与目标

Qwen3-VL-Seg 是阿里在 2026 年 5 月发布的视觉-语言分割模型，将 Qwen3-VL 的多模态理解能力扩展到像素级分割。Qwen3.5-0.8B是 Qwen 系列最新的轻量级视觉-语言模型，参数量 0.8B，具备统一的视觉-语言理解和原生 2D grounding 能力。相比前代 Qwen3-VL-2B，Qwen3.5 的主要变化包括：(1) 模型架构升级为 Qwen3_5ForConditionalGeneration，视觉编码器和语言模型内部结构不同；(2) 支持思考模式；(3) ViT 更紧凑，但 grounding 精度相当；(4) 参数量仅为 2B 的 40%，训练和推理速度更快。本实验将 ViT 和 LLM 冻结，训练约 11.6M 参数的 Mask Decoder，在 Pascal VOC 2012 全 20 类上进行验证。

推理采用两遍前向策略：第一遍由 LLM 自回归生成 bbox JSON，第二遍插入 mask token 后前向 LLM 提取语义查询 h_mask，与 bbox 编码、多尺度 ViT 特征融合后经 Mask Decoder 预测分割掩膜。

本次实验对比了三组条件：(1) Qwen3.5-0.8B 单类 person 训练，(2) Qwen3.5-0.8B 20 类联合训练，(3) Qwen3-VL-2B-Instruct 单类 person 训练（历史对照）。

6. 问题诊断与解决

问题 1：LoRA 训练破坏 VLM 原生 Grounding 能力

现象：LoRA (rank=8) 训练 LLM 输出结构化 JSON 后，模型生成崩溃为 <|im_start|> 循环。token 级别诊断显示训练目标中 assistant 后首个 token 与基座模型强先验冲突。

根因：极小规模单一数据 (600 张 person 图像) + 单一 prompt + 冻结输出格式，LoRA 在极窄分布上反复施加同方向梯度，覆盖了 2B 基座模型中 bbox 输出通路的关键参数。

解决：LLM/ViT 完全冻结，仅训练 Mask Decoder。

问题 2：手动 Token 生成与 Processor 输入异常

现象：手动逐 token 调用 llm_decoder() 生成序列与基座模型不一致；直接传入 tensor 给 processor 导致 ViT 特征失真。

解决：统一使用 base_model.generate()；processor 前将 tensor 转为 PIL Image。

问题 3：LLM Bbox 与 GT Bbox 分布偏差

现象：GT bbox mIoU 0.80 vs LLM bbox mIoU 0.61，差距 0.19。

解决：训练时对 GT bbox 施加 ±10% 独立角点噪声，mIoU 提升至 0.72 (+0.11)。

问题 4：多人场景非首个实例丢失

现象：仅解析 JSON 首元素，多人场景覆盖率 65-70%。

解决：解析全部 bbox → per-instance mask decode → pixel-wise max merge，覆盖率升至 85-98%。

问题 5：多类 Prompt 导致 VLM 性能退化

现象：20 类联合 prompt 下 LLM mIoU 0.572 vs GT 0.752 (gap 0.18)。而单类 prompt 下 gap 仅 0.02-0.04。

根因：多类 prompt 列出 20 个类别名，在复杂共现场景中 VLM 注意力分散，导致漏检或标签混淆。动物类（单独出现）gap < 0.07，共现类（diningtable+chair, person+car）gap > 0.25。

结论：推荐实际使用单类 prompt（逐类查询），VLM 的 per-class grounding 精确可靠。

7. 结论与后续方向

  1. Mask Decoder 架构验证成功：class-agnostic 设计正确，20 类联合训练 GT 上限 0.752，多类数据提升单类性能。
  2. Qwen3.5-0.8B 性价比优异：以 40% 参数量达到 2B 的 97% mIoU，训练+推理均更快。
  3. Prompt 格式是关键变量：单类 prompt 下 VLM grounding 精确 (gap ~0.02)，多类 prompt 显著退化 (gap ~0.18)。
  4. 架构瓶颈在细长物体：stride=4 的 mask 输出对 chair/bicycle/pottedplant 等细长结构分辨力不足。减小 stride 或增大 decoder 容量可能进一步提升。
